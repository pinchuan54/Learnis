# 计时器拖动原型

拖动调整计时器时间（#36）的交互原型，用来对齐手感和交互，也方便以后调手感、做新皮肤时接着用。它只是一个独立的网页，不参与构建，也不会进安装包。

## 怎么打开

双击 `index.html`，用浏览器打开即可，不需要安装依赖或启动开发服务器。

## 可以试什么

- **电子计时器**：在时、分、秒上按住上下拖，往上加、往下减；也可以用滚轮和方向键。
- **物理秒表**：按住表盘，抓起离点击方向最近的分针或秒针转动；点小表盘抓的是小时指针。
- **甩出去**：松手时还在动，会按速度继续转，再被阻尼刹住；落点顺着最后的方向取整，松手后无缝并入正常走秒。
- **倒计时 / 正计时**：倒计时显示剩余，超过目标后变成橙色的「额外学习」；切换时每一位数字各自滚到新值。
- **一轮调整**：停手约 5 秒前的几次调整算同一轮，正在操作的那个表下面显示这一轮的合计，可以整轮撤销。
- **外观**：右上角切换浅色 / 深色 / 跟随系统，新外观从按钮处以圆形展开。

页面里的「今天」是模拟的：现在是 15:00，计时记录 53 分钟，今天目标 2 小时 5 分钟。

## 手感参数

参数面板的默认值就是软件里「阻尼滚轮」的预设。调过的数值只存在当前浏览器里，点「恢复默认」回到预设，点「复制」可以把整组数值记下来。

| 参数                | 预设               | 含义                                                                      |
| ------------------- | ------------------ | ------------------------------------------------------------------------- |
| 秒 / 分 / 时的速度  | 99% / 60% / 105%   | 数字移动的距离和鼠标移动距离之比，100% 就是完全跟手；秒表指针按同样的比例 |
| 快拖加速            | 0.5                | 拖得很快时额外多走几格，0 就是不加速（只对电子计时器）                    |
| 滚轮 · 秒 / 分 / 时 | 0.7 / 0.7 / 0.5 格 | 滚轮每滚一格走几格                                                        |
| 重量感              | 80 ms              | 数字追上鼠标要多久，越大越沉                                              |
| 松手后滑行          | 35                 | 甩出去以后还能滑多远                                                      |
| 甩出力度            | 0.6×               | 同样的甩速，转出去多少                                                    |
| 走秒动画            | 1397 ms            | 平时每秒数字滚动的时长；1 秒以上时数字会一直缓缓地走                      |

## 结构

和 #34 里约定的三层一致，正式实现也按这个拆分：

1. **时间规则**：进位、借位、边界（今天合计不低于 0、不超过今天已经过去的时长），停稳后记一笔手动修正。
2. **手感**：只处理一个数（这次拨动了多少秒），负责跟手、惯性、阻尼、吸附和收尾，与外形无关。
3. **皮肤**：负责画，并说明哪些部件能拖、拖多远等于多少时间（数字上下拖一格 = 1 个单位，分针转一圈 = 60 分钟）。
